# Plan: Phase 06-01 — RTMP Output Integration

## Objective
Implement the server-side logic to relay TTS audio chunks to configured RTMP destinations using FFmpeg.

## Wave 1: Streamer Engine
- [ ] Create `src/lib/rtmp-streamer.ts` class.
  - [ ] Implement `spawnFFmpeg` with tee muxer configuration.
  - [ ] Implement `pushAudio` method (stripping WAV headers if necessary).
  - [ ] Implement `stop` method for clean process termination.
  - [ ] Add event handlers for FFmpeg error monitoring.

## Wave 2: Server Orchestration
- [ ] Update `server.ts` to include `RTMPStreamer` in the session state.
- [ ] Modify `GO_LIVE` command:
  - [ ] Fetch all enabled channels for the user from MongoDB.
  - [ ] Decrypt RTMP stream keys.
  - [ ] Initialize `RTMPStreamer` with channel configs.
- [ ] Update pipeline callback:
  - [ ] When a TTS output is received, pipe it to the corresponding channel in the streamer.

## Wave 3: UI & Reliability
- [ ] Update `SESSION_SNAPSHOT` to include RTMP status per channel.
- [ ] Implement auto-restart for FFmpeg on connection drops (optional, but recommended).
- [ ] Add logging for stream connection/disconnection events.

## Verification Criteria
- [ ] `RTMPStreamer` correctly spawns FFmpeg with the expected `tee` arguments.
- [ ] Audio chunks sent to `server.ts` are successfully pushed to FFmpeg's `stdin`.
- [ ] External RTMP player receives audio with < 5s additional latency over pipeline time.
- [ ] FFmpeg process is killed when the session stops.
