# Plan: Phase 07-01 — Performance & UI Polish

## Objective
Optimize the data transport layer and refine the user interface to ensure a low-latency, premium streaming experience.

## Wave 1: Transport Optimization
- [ ] Implement Binary WebSocket transfers for `AUDIO_CHUNK`.
  - [ ] Update `obs-relay-client.ts` to send raw `ArrayBuffer`.
  - [ ] Update `server.ts` to handle binary messages using `ws.on("message", (data, isBinary) => ...)`.
- [ ] Fine-tune FFmpeg flags in `src/lib/rtmp-streamer.ts`.
  - [ ] Add `-fflags nobuffer -flags low_delay -probesize 32`.

## Wave 2: Latency Monitoring & Feedback
- [ ] Update `SessionSnapshot` and `sessionManager` to track average pipeline latency.
- [ ] Add a "Latency Monitor" to the `PipelineMonitor` or `SessionStats` UI.
  - [ ] Show real-time delay (e.g., "Latency: 3.2s").
- [ ] Implement "Skeleton" states for `SessionStats` to prevent layout shift on start.

## Wave 3: UI Refinement
- [ ] Integrate `sonner` for elegant toast notifications.
- [ ] Refine `PipelineMonitor` animations.
  - [ ] Add a smooth "scanning" gradient to active stages.
- [ ] Fix any minor glassmorphism inconsistencies (borders, blurs).

## Verification Criteria
- [ ] `AUDIO_CHUNK` messages in Chrome DevTools show as binary frames.
- [ ] End-to-end latency is reduced by at least 1 second compared to Phase 06.
- [ ] Dashboard start/stop transitions are smooth with no flickering.
